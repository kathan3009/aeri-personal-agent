# Two-minute rehearsal

1. Open Aeri on a phone. Show the three calm tabs: Agent, Memory, Tasks.
2. Record a short kitchen clip. Confirm tomatoes, reject one mistaken item. In Memory, show that guesses required user review.
3. Paste a public recipe YouTube link. Review the actual extracted recipe and its missing ingredients. Remove an unwanted cart item, then approve.
4. Open Kernel checkout. Verify products in the retailer live view and complete checkout yourself. Do not call a prepared browser a placed order.
5. Say “We used two eggs” by voice. Aeri transcribes, updates confirmed memory, and speaks a reply. Create another recipe plan and show the new quantity changes the cart.
6. If Vapi is live, call the paired number and invoke `read_memory`; show the same state in the app. Show AgentMail receipt evidence only after a signed real webhook is observed.

## Gates before claiming a live demo

- Physical phone: camera video capture/upload, voice recording/playback, app reopen and LAN/API connectivity.
- Gemini: one real YouTube recipe and one real kitchen video inspected and corrected.
- Kernel: authenticated retailer, two products added, quantity/availability checked, live checkout handoff.
- Vapi: successful inbound call from the allowed number and a tool call visible in the app.
- Hosted API: Neon persistence survives a server restart; secrets are in Fly, not the mobile bundle.

Key-free mode is a product/UI demonstration, explicitly labeled as such. Sponsor-backed behavior is activated and tested when credentials arrive.
